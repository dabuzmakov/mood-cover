# Проект 4. MoodCover

Генератор атмосферных PNG-изображений на основе алгоритма **fractal flame**
и идеи **Chaos Game**. Такие картинки музыкальный сервис мог бы использовать
для обложек плейлистов или экрана «сейчас играет»:

```text
mood-cover --width 1920 --height 1080 --iterations 2500 --seed 42 --output result.png
```

Сначала делается однопоточный рендерер, который по конфигу рисует изображение.
Затем многопоточная версия и benchmark, который честно показывает, насколько
она быстрее.

Главное в этом проекте — не картинки, а **многопоточность на честной задаче**.
Генерация упирается в процессор: сделать корректную однопоточную версию,
распараллелить её без гонок и, самое важное, **измерить** результат.

Задание разбито на три merge request'а. Делай их по очереди.

---

## Быстрый старт

```bash
dotnet build                              # собрать решение
dotnet run --project src/MoodCover.App    # запустить программу
dotnet test                               # все тесты (юнит + интеграционные)
dotnet format --verify-no-changes         # проверить форматирование (ровно то, что в CI)
```

Нужен **.NET 10 SDK или новее**. NuGet-пакеты тянутся из внутреннего
Artifactory-фида (см. `nuget.config`).

## Запуск тестов отдельно

```bash
dotnet test src/MoodCover.Tests/MoodCover.Tests.csproj                 # юнит
dotnet test src/MoodCover.IntegrationTests/MoodCover.IntegrationTests.csproj   # интеграционные
```

Интеграционные тесты поднимают приложение отдельным процессом (`CliRunner`)
и проверяют поведение настоящего исполняемого файла.

**Этот файл — твой.** Опиши здесь, что получилось, как это запускать и какие
решения ты принял. Обновление README входит в чеклист каждого merge request'а.
