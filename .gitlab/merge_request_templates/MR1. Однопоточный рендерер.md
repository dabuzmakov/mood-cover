## Требования MR1

- [ ] Генерация точек через Chaos Game
- [ ] Аффинные преобразования
- [ ] **Минимум 4 нелинейные трансформации** (на выбор: `linear`, `sinusoidal`,
      `spherical`, `swirl`, `horseshoe`, `polar`, `heart`, `disk`, ...)
- [ ] Цветная генерация
- [ ] Накопление попаданий в пиксели
- [ ] Сохранение в PNG

```text
Render(config, random) -> Image
```

Аффинное преобразование — шесть чисел `a,b,c,d,e,f`:

```text
xNew = a * x + b * y + c
yNew = d * x + e * y + f
```

### Инварианты

- [ ] `width > 0`, `height > 0`, `iterationCount > 0`
- [ ] Output заканчивается на `.png`
- [ ] Трансформации не пусты, веса положительны
- [ ] Результат воспроизводим по `seed`
